# 📈 Stock Price Prediction Using Machine Learning

## 🎓 University AI Course Lab Final Project

This project was developed as the **Final Project** for our **University Artificial Intelligence (AI) Course Lab**.
The project demonstrates the practical implementation of **Machine Learning** and **Deep Learning** techniques for predicting stock prices using historical market data.

The main goal of this project is to apply AI concepts in a real-world financial prediction system while gaining hands-on experience in model training, data visualization, and web application deployment.

---



## 📌 Project Overview

This repository contains a machine learning-based stock price prediction system designed to forecast stock prices of multinational companies (MNCs) for the next **30 days**.

The application uses historical stock market data and deep learning algorithms to analyze trends and generate predictions.
A user-friendly interface built with **Streamlit** allows users to interact with the system easily and visualize prediction results in real time.

The project includes:

* 📊 Data preprocessing and cleaning
* 🤖 Machine learning & deep learning model training
* 📈 Stock trend visualization
* 🌐 Interactive Streamlit web application
* 🔮 Future stock price prediction

## ⚙️ Setup and Installation

To run this project locally, follow the steps below:

### 1️⃣ Clone the Repository

```bash id="9rkqgb"
git clone https://github.com/MdFarhadHossenImon/Stock-Price-Prediction-Using-Machine-Learning.git

cd Stock-Price-Prediction-Using-Machine-Learning
```

---

### 2️⃣ Create a Virtual Environment

```bash id="b6ikf8"
python -m venv env
```

Activate the environment:

#### Windows

```bash id="f5gxyo"
env\Scripts\activate
```

#### Linux / Mac

```bash id="0ydzxh"
source env/bin/activate
```

---

### 3️⃣ Install Dependencies

```bash id="r5wk94"
pip install -r requirements.txt
```

---

### 4️⃣ Run the Streamlit Application

```bash id="z7j62o"
streamlit run main.py
```
